# trackfolio

TUI Rust per un libro personale di T-Bill USA e depositi USD/EUR: capitale, yield ponderato, proiezioni e CRUD posizioni.

## Prerequisiti

- [Rust](https://www.rust-lang.org/tools/install) (stable)

## Installazione

```bash
cargo install --path .
```

## Dati

Il portfolio viene salvato in `~/.local/share/trackfolio/portfolio.json` (override con la variabile d'ambiente `TRACKFOLIO_FILE`).
